# Сервер «Зубрёжки»

Облачная функция в Яндекс Облаке: вход через Telegram, болталка группы, «Кто что отвечает» под лекциями, прогресс в аккаунте.
Сайт без неё работает как раньше — всё это просто скрыто (пустой `src/api_url.txt`).

## Как устроено
- `index.py` — функция (`index.handler`, python312). Запросы сайта: `POST` с JSON `{a: действие, t: токен, …}` и `Content-Type: text/plain` (без CORS-preflight). Вебхук бота входа — `POST ?tg=1`.
- `db.py` — база: YDB (Serverless) в Облаке, SQLite для локальной проверки.
- `test_server.py` — проверка всей логики без Облака и Telegram: `python3 server/test_server.py`.

## Вход
Сайт берёт одноразовый код (`login_start`) → открывает `t.me/zubrezhka_s201_bot?start=<код>` → «Старт» → бот входа. ⚠️ Telegram и Яндекс Облако НЕ достают друг до друга (ни вебхук, ни запросы из Облака), поэтому бот входа работает в GitHub Actions: `bot/login_relay.py` (опрос getUpdates → пересылает на сервер `?tg=1` с секретным заголовком → выполняет ответ сервера в Telegram), workflow `.github/workflows/login-bot.yml` — смены по ~5 ч 50 мин, расписание каждые 20 мин ставит следующую. Диагностика: `<адрес>?diag=1`, `?net=1`, Actions → «Проверка бота входа». Из Яндекс Облака серверы Telegram НЕДОСТУПНЫ, поэтому в Telegram сервер не ходит: бот входа сидит в чате группы (режим приватности выключен) и по вебхуку запоминает участников (таблица `members`: кто пишет, вступает, выходит). Группа и админ запоминаются, когда бота добавляют в чат (`cfg`: group, admin = кто добавил); в чужих группах бот выходит. Если человека ещё не видели — «напиши что-нибудь в чат», и сайт пускает сам (`notseen` → `ok`). Токен подписан, живёт 120 дней.

## Выкладка
Сама, через GitHub Actions (`.github/workflows/deploy-server.yml`) при изменениях в `server/`: тесты → функция → вебхук бота.
Секреты репозитория: `LOGIN_BOT_TOKEN` (бот входа), `TELEGRAM_BOT_TOKEN` (бот домашки, для проверки участия в чате), `SESSION_SECRET` — по желанию.
Адрес функции — в `src/api_url.txt` (после смены — `python3 src/build.py`, версия кэша в `sw.js`).

## Сайт
Код — раздел «аккаунт…» в `src/app.js`, стили — в конце `src/app.html`.
- 🔑 Вход/аватар в шапке главной, окно входа.
- 💬 `#chat` — болталка (опрос сервера каждые 4–15 с, пока открыта).
- 🙋 Вкладка «Кто что» у лекции: вопросы (можно вставить списком), «Беру», 📋 список для чата группы, обсуждение лекции.
- ☁️ `known`, `best`, `examKnown` из localStorage синхронизируются с аккаунтом.

## 🔔 Уведомления в Telegram (с 12 ноября 2026)
Новое ДЗ и изменения расписания приходят в личку от бота входа всем, кто вошёл на сайт и сейчас в чате группы. По умолчанию всё включено.
- Настройки: сайт (аватарка → «Уведомления», `notif_get` / `notif_set`) или команды боту входа `/off`, `/on`, `/hw`, `/sch`, `/notify`. Хранятся в `cfg` под ключом `nt:<uid>` (`hw,sch`), новых таблиц нет.
- Рассылает `bot/notify.py` из GitHub Actions (Облако до Telegram не достаёт); список получателей — `POST ?tg=1&subs=1` с секретом моста.
- ДЗ из чата — сразу после записи `homework.json` ботом домашки. Расписание и ДЗ, поправленное вручную, — `.github/workflows/notify.yml` при push в main. «[тихо]» в сообщении коммита — без рассылки.
